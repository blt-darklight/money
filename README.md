# 每日收益 · 跨平台自动汇总

> ⚠️ **如需使用本仓库**：`portfolio.db` 是作者的示例/个人数据，请先删除它（或改名备份），
> 首次运行会自动生成一个空的新数据库；`.streamlit/config.toml`、`hutao.jpg` 为界面样式与背景图，可按喜好替换。

本地运行的单页 Web 应用：每天手动录入同花顺、养基宝的「**当日市值**」和「**总收益（累计）**」，
自动跨平台汇总、推算每日收益、画图，保存在本地 `portfolio.db`（SQLite 单文件，无需装数据库）。

## 功能

- 点「✏️ 录入数据」按钮在弹窗中填写，**两种方式可混用**（每个平台各自选）：
  - **方式① 市值 + 总收益**：照 App 抄两个数；市值可留 0 = 今天不记市值
  - **方式② 当日收益**：只抄一个数，市值/总收益自动按上一条记录推算
    （总收益 = 上一条总收益 + 当日收益；市值 = 上一条市值 + 当日收益；
    该平台还没录过时，当日收益就当作首期盈亏）
- 只想录一个平台：取消勾选另一个再保存；同日同平台重复保存 = 覆盖
- **每日收益自动推算**：当次总收益 − 该平台上一条总收益；
  **每平台首条记录**把它的总收益整体当作首期盈亏——也就是把你建仓以来已有的收益
  算进首日（首月 / 首年同样如此），这样开头不会是一段空白
- **收益率走势 = 自建仓累计收益率**：分母固定 = 第一天倒推的初始本金
  （第一天市值 − 第一天总收益）。第一天就显示真实收益率（不再从 0 起），
  每天数值 = 当天总收益 ÷ 初始本金；本周 / 本月 / 本年 / 全部只决定显示哪一段
- **收益率走势**：× 总收益 / 分平台 / 全部叠加，
  可**叠加 A 股指数对比**（上证指数 / 沪深300 / 创业板指 / 科创50 / 中证500，指数线为琥珀色），
  图下方对比条按所选时间范围显示区间收益率与指数同期涨跌（跑赢/跑输）
  指数同用建仓日为起点算累计涨跌，图下方显示跑赢/跑输多少个百分点
- **盈亏日历**（仿养基宝卡片网格）：日（周一~周五日格，当日实心高亮）/ 月（12 月卡）/
  年（年卡）× 收益率 / 金额切换，底部显示累计收益与同期上证指数涨跌
  （日历里的收益率是**当期口径**：当期赚的钱 ÷ 期初市值）
- 界面仿养基宝：蓝色渐变总览卡（当日总收益 / 当日收益率 / **累计收益率** / 总市值 / 总收益）
  + 居中窄栏白色卡片分区
- 明细数据（含当日收益率）、月度统计（收在底部折叠区）
- 手机在同一 WiFi 下可访问（局域网模式）
- 单张固定背景：项目目录放置 `hutao.png / hutao.jpg` 等图片即自动生效（当前已内置 hutao.jpg），
  背景固定跟随屏幕、不随内容滚动
- 蓝白主题（仿养基宝）：项目内 `.streamlit/config.toml` 强制浅色主题 + 蓝色主色调；
  图表统一白底；盈亏柱状与日历保留「红盈绿亏」习惯配色

## 快速开始（本机已配好）

1. 双击 `start.bat`
2. 浏览器自动打开 `http://localhost:8501`；关掉黑窗口即退出程序

> 依赖已安装在 WorkBuddy 托管的独立虚拟环境
> `C:\Users\walnut\.workbuddy\binaries\python\envs\default`，不污染系统 Python。
> 首次运行自动建库建表（`portfolio.db` 首启自动生成）。

## 每日使用流程

1. 收盘后打开两个 App，各抄 2 个数：**当日总市值**、**总收益（累计）**
2. 点页面顶部「✏️ 录入数据」按钮，在弹窗表单里选好日期（默认今天），填入数字点「保存」，
   保存后点弹窗右上角 ✕ 返回，指标与图表自动刷新
3. 顶部指标和图表自动更新；填错直接改数再保存一次即可覆盖
4. 某天只想录一个平台：取消勾选另一个平台的「今日录入」再保存
   （取消勾选并保存 = 移除该平台当日记录；总市值/总收益会沿用它最近一次的值，
   不出现假跌。误勾掉了也没关系：重新打开弹窗——数值还在——勾选回来再保存一次即可恢复）

> **关于推算的每日收益**：它等于两次录入总收益的差值；但**每平台的第一次录入**没有
> 上一条可比，此时直接把当次「总收益」整体当作首期盈亏（首日日历格、首月、首年都能
> 看到这笔建仓以来的收益）。当天有申购/赎回（出入金）时，差值会把出入金算成"收益"，
> 数字会失真——属预期行为，看趋势即可。
>
> **关于收益率（两种口径）**：
> - **走势图 / 总览卡累计收益率** = 自建仓累计：分母固定为**第一天倒推的初始本金**
>   （你录入的第一天：市值 − 总收益）。所以第一天就有真实收益率，不是从 0 开始；
>   之后每天都用同一个本金做分母，曲线是「自建仓以来赚了百分之几」。
>   走势卡底部会把这几个初始本金列出来，方便核对。
> - **日历 / 当日收益率** = 当期口径：当日（当月 / 当年）赚的钱 ÷ 期初市值。
> - 第一天如果没填市值，程序会自动往后找第一条有市值的记录来倒推；
>   完全没市值的平台不参与收益率（走势图跳过它，金额类数值不受影响）。

## 手机访问（同一 WiFi）

1. 电脑上 `Win+R` 输入 `cmd` 回车，运行 `ipconfig`，记下「IPv4 地址」（如 `192.168.1.100`）
2. 手机浏览器打开 `http://192.168.1.100:8501`
3. 首次启动时若弹出 Windows 防火墙提示，勾选「专用网络」并点「允许访问」

## 数据与备份

- 所有数据都在程序目录的 `portfolio.db` 一个文件里，**备份 = 复制这个文件**
- 首次运行自动建库建表；删除该文件即彻底重置（慎用）
- 同一日期同一平台重复保存会覆盖旧值
- 旧版数据库（v1，含"当日收益"字段）会在启动时**自动升级**：原数据迁入新表
  （总收益保留、市值留空待补录），旧表保留为 `records_v1_backup`，确认无误后可手动删除
- 数据文件损坏时，用最近的备份副本覆盖回去即可

## 常见问题

| 问题 | 处理 |
|---|---|
| 端口 8501 被占用 | 编辑 `start.bat`，把 `--server.port 8501` 改成 `8502`（手机访问端口同步改） |
| 双击 start.bat 一闪而过 | 在该目录打开 cmd，手动运行 `start.bat` 查看报错 |
| 换新电脑部署 | 装 Python 3.9+ → `pip install -r requirements.txt` → 编辑 `start.bat` 里 `set "PY=..."` 指向新环境的 python.exe |
| 想加第三个平台 | 编辑 `app.py` 顶部 `PLATFORMS = ["同花顺", "养基宝", "新平台"]`，重启程序即可 |
| 指数对比曲线不出现 | 需要联网（数据来自东方财富公开接口，缓存 1 小时）；离线时自动跳过叠加，其余功能不受影响 |
| 浏览器没自动打开 | 手动访问 `http://localhost:8501` |
| 当日收益数字不对 | 它是总收益差值推算的：当天有申赎就会失真，属预期；漏录平台那几天，该平台变动会算到下一次录入那天 |
| 某天录错了想删掉 | 直接把当天的数字改成正确值重新保存即可（覆盖）；确实需要删除记录时，先备份再用 SQLite 工具删行 |

## 数据表结构

```sql
CREATE TABLE records(
    date         TEXT,   -- 'YYYY-MM-DD'
    platform     TEXT,   -- 平台名
    market_value REAL,  -- 当日总市值
    total_pnl    REAL,  -- 总收益（累计）
    PRIMARY KEY(date, platform)
);
```
